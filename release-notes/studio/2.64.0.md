本版把侧栏重做成时间线，把"拖拽换位置"做成一套看得见的语言，并让模型的名字来自接入的门——喜鹊网关给的自定义名称现在直接显示，不用再自己认。

## 侧栏 · 时间线

- **时间线阅读**：时钟按钮（全部左侧）打开平铺时间线——每个会话一行，名字在上、归属在下，按 今天 / 昨天 / 7天内 / 30天内 / 更早 分组，右侧是相对时间 (8e888ee)
- **最近离开范围菜单**：范围筛选只留六个范围，最近排序变成自己的时钟按钮；选中的范围以着色标识 (8e888ee)
- **空状态**：项目 / 任务各自站着，空时说 暂无项目 / 暂无任务 (8e888ee)
- **组头折叠持久化**：项目 / 任务标签折叠整组（行收走只剩标签），重开窗口记住形状；搜索会揭开被折叠的行 (14f8c4d 后续轮)
- **文件夹图标即折叠**：项目行左缘的单独箭头取消，折叠状态由文件夹图标自己开/合表达，图标与左侧导航对齐 (本轮)

## 侧栏 · 拖拽

- **一套插入线**：组标签行、项目行、会话行的拖拽都画同一条 2px 提示线在落点边缘，跟随指针；被拖的行淡显 (本轮)
- **会话行拖拽**：行拖到目标行上沿或下沿即落位，跨门拖一次只刷新一次 (8e888ee + 本轮沿语义)
- **组标签互换**：拖 项目 到 任务（或反过来）互换两组位置——旧版"被拖的组变第一"在已领先的组上是无效手势，现改为真互换 (本轮)
- **拖影变轻**：拖动时跟随的是一枚小名字胶囊，不再是整行的半透明快照——长侧栏的拖动不再发卡 (本轮)

## 侧栏 · 加号

- **项目 / 任务组头右缘各一枚加号**，悬停显现、与整行同一条高亮（带细微色差）：项目的加号在按钮左下角弹出「新建空白项目 / 使用现有文件夹」，任务的加号直接开一个非项目新会话 (本轮)
- **新建空白项目对话框**抽成共用组件，胶囊与侧栏同一份 (本轮)

## 会话互聊

- **常驻条撤了**：派发出去的会话读成仪表条里一枚安静的「会话互聊 N」芯片，悬停或聚焦弹出小卡，逐个列出对端与回信状态，灯标可点开对应会话 (本轮)
- **名字不再出现 undefined**：角色随派发记录在发送方自己的记忆里，对端面板关掉之后行上仍有名字 (本轮)
- **侧栏行悬停卡**：悬停会话行半秒，浮出标题、项目、目录、最近更新，以及该会话派发过的每条任务——点一行直达落点的会话。内核新增 `GET /dispatch-threads?path=`，按发送方会话路径记录 (本轮)

## 模型名字来自门

- **供应商前缀隐藏**：`group/`、`auto/`、`workbuddy/`、`qoder-cn/` 等前缀不再出现在模型菜单——每个模型按最后一段读取，两扇门指向同一模型就同名，门标题负责区分 (本轮)
- **名字自动来自门**：内核启动时对没有别名的门自动读取一次其列表的 `display_name`（喜鹊的"自定义名称不带供应商"），写入空别名——菜单显示门给的名字，零手工；自己设过的别名永远优先 (本轮)
- **异形 id 的图标**：qoder 的 `gfmodel` 显示智谱、`fast` 显示千问、`mmodel` 显示 MiniMax 等——按 id 对照表给家族图标 (本轮)
- **五个新门图标**：Hugging Face、Novita AI、Kilo Code、GMI Cloud、Token Rhythm (本轮)

## 对话

- **消息时间戳**：每条消息带着落时间，悬停显示；设置 → 对话显示里「消息时间」开关，默认开 (bf2db51)
- **对话轮次**成为带图标的按钮，点开信息卡；发送/暂停按钮缩至文字行高度 (71dfada)

## 修复

- **组头折叠失效**：上一轮把组头折叠的接线弄丢了，真实应用里点 项目/任务 标签无反应——已接回并按行收走的语义持久化 (本轮)
- **会话互聊行显示 undefined**：对端面板关闭后角色查不到——现在角色随配对存进发送方内存 (本轮)
- **浮窗飘走**：弹窗锚点除以页面缩放系数——侧栏的菜单与悬停卡贴着各自的按钮走 (本轮)

<!-- lang:en -->

This release rebuilds the sidebar as a timeline, makes drag-and-drop a visible
language, and lets model names come from the door — a magpie gateway's custom
names now display as given, with nothing recognized on our side.

## Sidebar · timeline

- **Timeline reading**: a clock button (left of 全部) flattens the tree — one
  row per conversation, grouped under 今天 / 昨天 / 7天内 / 30天内 / 更早,
  relative dates on the right (8e888ee)
- **最近 left the scope menu**: six scopes remain, recency sort became its own
  clock button, chosen scopes ink (8e888ee)
- **Empty states**: 项目 / 任务 stand on their own and say 暂无项目 / 暂无任务
  (8e888ee)
- **Run folds persist**: the 项目 / 任务 labels fold their whole run to the
  label, and a reload opens the same shape; a search reveals folded rows
- **The folder icon is the fold**: no separate chevron on project rows — the
  icon opens and closes with the run, aligned with the nav icons above

## Sidebar · drag

- **One insertion line**: group-label rows, project rows and conversation rows
  draw the same 2px bar at the edge a drop will land at; the carried row fades
- **Session-row drag**: drop on a row's top or bottom half; one reload per
  gesture (8e888ee)
- **Group swap fixed**: dropping one label on the other swaps the runs — the
  old "carried run leads" rule made the common gesture a silent no-op
- **A lighter drag ghost**: a small name chip follows the pointer instead of
  the browser's snapshot of the whole row

## Sidebar · plus

- **A plus on each group head**, revealed on hover inside the same bar: the
  projects' opens 新建空白项目 / 使用现有文件夹 at the button's corner, the
  tasks' opens a non-project conversation
- The blank-project dialog moved to a shared component, used by the pill and
  the sidebar alike

## Peers

- The standing cross-chat bar is gone: dispatched sessions read as one quiet
  chip in the meter rail; hovering it opens the card listing each peer and its
  reply state, lamps opening the session
- **No more undefined**: a dispatch's role rides the sender's own memory, so a
  closed partner's row keeps its name
- **The sidebar's hover card**: hovering a session row opens title, project,
  folder, last move and one line per dispatched task, each opening the session
  it landed on. Kernel serves `GET /dispatch-threads?path=`

## Model names come from the door

- **Vendor prefixes hidden**: `group/`, `auto/`, `workbuddy/`, `qoder-cn/` no
  longer reach the menus — every model reads by its last segment, two doors
  onto one model read alike on purpose
- **Names arrive on their own**: once per process the kernel reads each door's
  listing and prefills blank aliases from `display_name` — magpie's "custom
  name without vendor" lands in the menus with no hand
- **Marks for shorthand ids**: qoder's `gfmodel` reads zhipu, `fast` reads
  qwen, `mmodel` reads MiniMax — icons follow the family behind the name
- **Five new vendor marks**: Hugging Face, Novita AI, Kilo Code, GMI Cloud,
  Token Rhythm

## Chat

- **Message timestamps**: each message carries its settled time, revealed on
  hover; the switch lives in 设置 → 对话显示, default on (bf2db51)
- **对话轮次** became a button with an info card; send/pause buttons shrank to
  the text row's height (71dfada)

## Fixed

- **Group folds did nothing**: the round had dropped the head-fold wiring from
  the Sidebar mount — restored, persisted as rows-gone
- **Peers rows read undefined**: the role now rides the sender's pair memory
- **Floaters drifted**: floater anchors divide by the page's zoom, so menus
  and hover cards sit at their buttons
