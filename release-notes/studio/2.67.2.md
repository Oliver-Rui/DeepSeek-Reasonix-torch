## 修复

- 安装包与更新清单重新由 CI 自动签名并发布：发布任务不再因为未启用 Certum 签名而被整体跳过，签名工具也接受本 fork 的密钥存储格式 (837fb29bd, 540014a1c)
- WebSocket 客户端不再用弱随机数生成掩码密钥，依赖升到修复该缺陷的提交（GO-2026-6278）(b34d76d04)

## 变更

- 执行权限菜单只保留四个档位：原先的「沙盒与运行边界」一栏带着箭头却直接跳去设置页，现已连同底部那句沙盒说明一起移除 (137a43f)
- 窗口变窄不再自动收起左侧工作区栏，右侧工作台的目录栏也不再在窄窗口消失：两栏都只听各自的折叠控件 (a52e0c4)
- 配置文件的 Windows 沙箱说明现在指明 `windows_integrity` 才是打开该限制的开关，不再声称 bash 在 Windows 上永远是关的 (ab5127ffa)

This release puts installer signing and publishing back on CI — the packages and the update
manifest are signed by the fork's own key — and upgrades the WebSocket dependency past its
weak-PRNG advisory. The config template's Windows sandbox note now names the real switch.

## Fixed

- Installers and the update manifest are signed and published by CI again: the publish job
  no longer skips wholesale because the Certum signing jobs are off, and the signing tool
  accepts the fork's key storage (837fb29bd, 540014a1c)
- The WebSocket client no longer derives its frame mask from a weak PRNG; the dependency
  moves to its fix commit (GO-2026-6278) (b34d76d04)

## Changed

- The execution-permission menu lists only the four modes: the sandbox entry, which drew a
  chevron but left for Settings, is gone, and so is the line beneath it (137a43f)
- Narrowing the window no longer collapses the workspace rail by itself, and the workbench
  keeps its tree below 760px; both columns answer to their collapse controls alone (a52e0c4)
- The config template's Windows sandbox note names `windows_integrity` as the switch that
  enables the restriction, instead of claiming bash is always off on Windows (ab5127ffa)
