This release folds the very-narrow-viewport overflow back in: the phone-fold tool row, the
model menu and the context card all stay inside the pane; the web access settings panel
adopts the shared settings row language; and the repository's only branch returns to `main`.

## Changed

- The repository's only branch returned from `torch` to `main` as the default; CI, CodeQL,
  Studio, the release workflow, the signing contract and the docs' branch gates follow the
  rename (0eb85fa)
- Release signing moves to this fork's own minisign identity: installers and the update
  manifest are signed by CI, and releases are no longer published unsigned (2bb6e6d)

## Fixed

- The phone fold no longer pushes the model tool row out of the pane's left edge; an
  over-long model name truncates to an ellipsis (b369ad8)
- At non-100% interface zoom, the context card, the model menu, the error bars, the toasts,
  the rename dialog and the phone card no longer escape narrow windows (b369ad8, 90b9b3d)
- The project pill aligns with the composer card's left edge, and the collapsed pill no
  longer squeezes two icons into its 30px rounded box (b369ad8)
- The auxiliary-session tip and the model menu render fully inside narrow windows (b369ad8)
- The phone drawer sizes against the zoomed viewport; a 320px window no longer overflows it
  (b369ad8)
- The web access settings panel speaks the shared settings row language: names and notes
  left, the reorder buttons and the switch right-aligned on the row, the billing consent
  indented under its backend, and the native bullets gone (e149f6f)

## Upgrade notes

- The signing key rotated in this version: upgrading from 2.67.0 or earlier, the in-app
  auto-update fails signature verification and the installer must be downloaded from this
  release page by hand; from 2.67.1 onward in-app update verification works (2bb6e6d)
