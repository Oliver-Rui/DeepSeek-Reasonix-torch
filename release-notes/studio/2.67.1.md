  Studio, the release workflow, the signing contract and the docs' branch gates follow the
  rename (0eb85fa).

## Fixed

- The phone fold (~≤340px) no longer pushes the model tool row out of the pane's left edge:
  an over-long model name truncates to an ellipsis and the shrink chain moved into the
  design layer so every layer's rules agree (b369ad8).
- Twelve viewport clamps across six sheets now divide by the interface zoom: at non-100%
  zoom the context card, the model menu, the error bars, the toasts, the rename dialog and
  the phone card no longer escape the window by the zoom factor (b369ad8, 90b9b3d).
- The project pill aligns pixel-for-pixel with the composer card's left edge in the side
  fold (b369ad8).
- The 30px collapse hides the project pill's chevron: two 14px icons no longer poke out of
  a 30px rounded box (b369ad8).
- The auxiliary-session tip clamps to the conversation container and the model menu takes
  the viewport's width on narrow windows (b369ad8).
- The phone drawer sizes against the zoomed layout viewport; a 320px window no longer
  overflows it by 3px (b369ad8).
- The web access settings panel speaks the shared settings row language: names and notes
  left, the reorder buttons and the switch right-aligned on the row, the billing consent
  indented under its backend, and the native bullets gone (e149f6f).
